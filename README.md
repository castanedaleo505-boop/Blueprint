# Blueprint

A daily routine app for skin, hair, facial hair, neck and posture. It lists what to do, how much, and in what order, with the day's lifting split in the middle of it. New things start one at a time and the rest follows the schedule rules for you.
Same layout and type as Redline, with the palette inverted: white, black and blue.
Works offline. All data stays on the phone it runs on.

Open the live page on an iPhone in Safari, tap Share, then Add to Home Screen.
